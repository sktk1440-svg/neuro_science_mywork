# neuro_science_mywork

For personal study. I will post my progress every week.

神経科学と深層学習の個人学習リポジトリです。毎週の進捗を記録していきます。

## 構成

| フォルダ | 内容 |
| --- | --- |
| [`deep-learning-from-scratch/`](deep-learning-from-scratch/) | 「ゼロから作るDeep Learning」の章ごとのノートとコード |
| [`notes/papers/`](notes/papers/) | 論文を読んだメモ |
| [`notes/study/`](notes/study/) | 神経科学などテーマ別の学習メモ |
| [`weekly/`](weekly/) | 毎週の進捗記録 |

## 進め方

1. 勉強した内容をノートやコードとして該当フォルダに追加する
2. 区切りのいいところでコミットする（例：「3章 パーセプトロン実装」）
3. 週に1回、`weekly/` にその週の振り返りを書く（[テンプレート](weekly/_template.md)）
