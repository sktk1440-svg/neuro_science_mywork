# ゼロから作るDeep Learning

章ごとにフォルダを作り、ノート（`notes.md`）とコード（`.py` または `.ipynb`）を置きます。

例:

```
deep-learning-from-scratch/
├── ch01-python/
│   ├── notes.md
│   └── numpy_basics.py
├── ch02-perceptron/
│   ├── notes.md
│   └── perceptron.py
└── ...
```
